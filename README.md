# OrbitLock — secure command & telemetry protocol for satellite ground links

Implementation of the *OrbitLock* project proposal: an SDLS-inspired link-security protocol, a satellite
simulator, a ground-station web console, a man-in-the-middle attacker toolkit, and an Isolation-Forest
telemetry anomaly detector — all talking over local UDP.

## Run

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python run.py            # console at http://127.0.0.1:5000   (add --secure to start secured)
.venv/bin/python -m pytest -q      # 32 tests: protocol, end-to-end attacks, asyncio/Scapy/pcap, report
.venv/bin/python -m orbitlock.evaluate   # full evaluation -> results/results.json, PNG plots, security_analysis.md
```

## What maps to what in the proposal

| Proposal item | Where |
|---|---|
| X25519 + HKDF-SHA256 session keys, PSK stand-in for pre-launch keys | `orbitlock/protocol.py` (`GroundHandshake`, `SatelliteHandshake`) |
| AES-256-GCM, header (SCID, VC, seq, …) as AAD | `SecureChannel.protect/unprotect` |
| Monotonic seq + sliding window, periodic rotation, emergency rekey | `ReplayWindow`, `SecureChannel.rotate`, `GroundStation.rotate_keys/emergency_rekey` |
| Security event log with reasons (bad tag / replay / out-of-window …) | `SecurityLog`, "Security events" panel |
| Ground console (set mode, attitude, downlink, live telemetry & events) | `orbitlock/web/` + `ground.py` |
| Satellite simulator (battery, temp, attitude, position) over UDP | `satellite.py` |
| Attacker: sniff, replay, forge, bit-flip, drop (+ flood, downgrade, telemetry spoof) | `attacker.py` |
| Isolation-Forest anomaly detector | `anomaly.py` |
| Evaluation plan (attack success, overhead, precision/recall/FPR) | `evaluate.py`, "Evaluation" tab |
| asyncio networking | `net.py` (`AsyncRuntime`, `UdpEndpoint`); each node runs its own event loop, receive paths, telemetry/physics, key-rotation, flood and downlink are asyncio tasks |
| Scapy | `scapy_layers.py`: `OrbitLock` Scapy layer (byte-identical to the native header), frames are crafted/dissected with it by the attacker, wire capture exports to `.pcap` (console button or `/api/capture.pcap`, opens in Wireshark) |
| Comparative security analysis | `report.py` -> `results/security_analysis.md` (regenerated by every evaluation run; linked from the Evaluation tab) |

## Design notes

* **Topology:** ground ⇄ attacker ⇄ satellite. The attacker is always in the path (passive relay until you
  trigger an attack), so identical attacks run against the *clear* and *secured* link — toggle at top right.
* **Frame:** 15-byte header `ver|scid|vc|type|epoch|seq`, then ciphertext + 16-byte GCM tag. Nonce = seq
  (keys are per-direction and per-epoch, so a nonce is never reused under one key). Overhead = 16 B/frame.
* **Auth before state:** the replay window is consulted/updated only after the tag verifies, so forged
  frames can neither burn sequence numbers nor be mis-reported as replays.
* **Rotation:** epochs ratchet forward (`root' = HKDF(root)`); a receiver accepts one epoch of look-ahead
  so a lost rotate command cannot desynchronise the link. **Emergency rekey** = REKEY telecommand + a fresh
  ephemeral X25519 handshake (new forward-secret session). Handshake replay is blocked by a monotonic counter.
* **Downgrade:** a secured satellite refuses cleartext frames (`clear_frame_on_secure_link`).
* **Ground truth:** `sim.py` judges attack success (spoofed / replayed / tampered command actually executed),
  independently of the protocol, so the "impact" counters are trustworthy.
* **Anomaly detector:** features are battery, temperature, their rates of change, attitude rate, and the
  satellite's received/rejected-frame rates. Isolation Forest cannot extrapolate beyond its training range,
  so it is paired with a range guard on delta/rate features (documented in `anomaly.py`).
* **Honest limits:** dropping frames is an availability attack no cryptographic layer prevents (it is shown as
  100 % in both modes and is *detectable* via missing ACKs). Not flight-grade, not full CCSDS, no RF layer.
  The Scapy layer crafts/dissects frames and writes pcaps but does not sniff a live interface
  (that needs root and a non-loopback path); the attacker is a relay node on the UDP path instead.
